# Community gallery

Each entry is a reproducible painting: a seed, a school, a city and a rendered image. The gallery
is a living index, not a portfolio.

The format and submission flow land with v1.0.0 (Phase 5). Until then this folder holds the
curation notes so the shape is not invented at the last minute.

## Planned entry

```json
{
  "title": "Bogotá, 4 °C at dusk",
  "city": "Bogotá, Colombia",
  "school": "turner",
  "seed": 1844,
  "renderedAt": "2026-11-02T18:40:00-05:00",
  "image": "./renders/bogota-1844-turner.png",
  "author": "Martin Pineda",
  "license": "CC BY 4.0"
}
```

Every entry must be reproducible from its URL. Images are shared under CC BY 4.0; the engine stays
MIT.
